# kdeck shortcut reference

Every shortcut and alias kdeck understands, with the full command it stands for (1174 entries).
Generated by `kdeck alias reference --markdown`; do not edit by hand (`make docs` regenerates it).

Look one up from the terminal:

- `kdeck alias explain kgpooyaml`: what a word expands to
- `kdeck help kgpo`: the expansion, then the help of the command it runs
- `kdeck alias reference logs`: this reference, filtered by a regex
- `kdeck alias set NAME 'EXPANSION'`: add your own; yours win over everything below

## Combination grammar

Words follow `[k][sys]<cmd>[<resource>][<modifiers>]`, as in kubectl-aliases. The leading k is optional after kdeck (`kdeck gpo` = `kdeck kgpo`). `sys` adds `--namespace=kube-system`. A value modifier (l, n, f) takes the next argument: `kgpol app=web` = `kubectl get pods -l app=web`. A word that is a real command is never expanded.

| Code | Expands to | Notes |
| --- | --- | --- |
| `cmd g` | `get` | takes a resource; modifiers: oyaml ojson owide a all w sl l n f |
| `cmd d` | `describe` | takes a resource; modifiers: a all l n f |
| `cmd rm` | `delete` | takes a resource; modifiers: a all l n f |
| `cmd a` | `apply -f` | no resource |
| `cmd ex` | `exec -i -t` | no resource; modifiers: n |
| `cmd lo` | `logs -f` | no resource; modifiers: n |
| `cmd lop` | `logs -f -p` | no resource; modifiers: n |
| `cmd p` | `proxy` | no resource |
